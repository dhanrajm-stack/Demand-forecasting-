Retail Store Inventory Dataset
Overview
The Retail Store Inventory Dataset contains historical retail data used for analyzing product sales and forecasting future demand.
This dataset can be used to build Machine Learning models for Retail Sales Demand Forecasting, inventory management, and sales analysis.
The dataset includes information about store locations, product categories, inventory levels, sales, pricing, and external factors such as weather and promotions.
Dataset Size
Total Records: 73,100
Total Features: 15 columns
This dataset can be used for:
Retail sales demand forecasting,Inventory optimization,Sales trend analysis,Price optimization,Machine Learning regression models
Machine Learning Applications
The dataset is suitable for building models such as:
Linear Regression,Random Forest Regressor,Decision Tree Regressor,Time Series Forecasting models
Example Use Case :
A machine learning model can be trained using the dataset to predict Units Sold based on factors like inventory level, pricing, seasonality, and promotions.
File type: CSV
File name: retail_store_inventory.csv
